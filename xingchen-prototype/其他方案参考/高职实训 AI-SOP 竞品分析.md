《高职实训 AI-SOP 竞品分析》

调研时间：2026 年 9 月 18 日

我把前面提到的厂商重新深挖了一轮，同时补查了 2025—2026 年最新招投标项目。结论比上一轮更明确：

“真实工位 + 摄像头/传感器 + AI动作识别 + SOP步骤判断 + 自动考评”已经开始进入职业院校采购，但目前市场仍处在“行业项目产品化”的早期阶段，还没有看到一家厂商把它真正做成覆盖多专业、可由老师低代码配置的通用 AI-SOP 教学平台。

这恰恰是值得关注的机会。

2026 年《职业院校人工智能应用指引》已经明确提出，在强调操作性的实训项目中，可以利用 AI 对学生进行实训引导与实操动作纠偏；对于任务链清晰、操作过程可分解的实训项目，可以通过 AI 分析技能操作行为。也就是说，你们这个方向已经与职业教育数字化建设路径高度重合。

而不是简单复制某一家。

二、第一重点竞品：捷安高科

捷安目前是我认为与你们整体方向最值得深入研究的一家。

2.1 它实际上已经把你们设想的东西做出来了一部分

包头铁道职业技术学院 2024 年智能高铁列车运行指挥虚拟仿真实训基地采购中，出现了非常完整的一套硬件软件组合：

项目	配置
动作识别终端	Dell 工作站 ×4，单价 8500 元
动作识别深度相机	奥比中光 Femto Bolt ×4，单价 3500 元
动作识别系统配件	捷安定制，50200 元
智能考评系统	捷安，55000 元

这不是概念宣传，而是政府采购中的实际货物清单。

这套结构非常有研究价值：

深度相机 → AI识别计算终端 → 动作识别 → 实训业务系统 → 智能考评。

这和我们之前讨论的系统架构几乎已经重叠。

2.2 捷安正在往“实物 + AI考评”继续深化

它的 2025 年年度报告披露了一个很重要的信息。

捷安已经完成“特种作业 AI 智能考试系统”，采用：

AI视觉识别 + 传感器融合 + 深度学习算法

形成：

实物设备 + AI考评

并明确写明已经实现“全流程 AI 考评落地”。

下一代产品已经覆盖：

低压/高压电工、焊接与热切割、高处作业等实操工种。

更值得注意的是，它还在研发“基于职教垂类大模型的 AI 职教平台”，目标包括互动问答、语音教学、自动评分、智能评价和内容生成。

这意味着捷安很可能正在从：

仿真实训设备厂商

往：

AI实训教学平台厂商

迁移。

对我们的启发

捷安证明了一件非常重要的事：

不能把视觉模型孤立起来。

它已经开始融合：

视觉识别 + 设备数据 + 传感器 + 教学系统 + 评分规则

这比单纯做 YOLO 视频检测成熟得多。

三、第二重点竞品：友道科技

友道最值得研究的不是摄像头，而是它对“动作”的理解方式。

它在轨道交通模拟驾驶系统里已经同时使用：

AI姿态识别 + 语音识别。

学生执行轨道交通标准的“手指口呼”：

手指向目标
+
说出对应口令
+
执行驾驶操作

系统捕捉训练过程，然后按照测评规则评分，并把需要改进的环节保存下来供教师查看。

这和机械实训非常相似。

比如以后做：

数控机床开机检查

完全可以设计为：

学生指向急停按钮
→ AI识别手势
→ 学生口述“检查急停按钮”
→ ASR识别
→ AI识别按钮状态
→ SOP引擎确认该节点完成。

这比“只识别学生有没有抬手”可靠得多。

2026 年 9 月，烟台工程职业技术学院城轨通信信号智能维保实训项目中，友道科技中标 A 包，中标金额 88.7 万元。需要注意，这 88.7 万元是整套铁路信号实训平台价格，不能理解成单纯 AI 动作识别系统价格。

对我们的启发

未来算法层最好不要定义为：

动作识别算法。

而应该定义成：

多模态实训事件识别。

一个步骤是否完成，可以同时依据：

人体动作 + 工具 + 工件状态 + 设备数据 + 语音 + 时间

共同判断。

四、宝华视联：最值得学习“学校产品怎么设计”

如果捷安适合学习系统架构，那么宝华最适合产品经理研究。

宝华现在给职业院校定义的系统已经覆盖：

实训教学 → 视频采集 → AI评价 → 视频复盘 → 教师复核 → 学情画像 → 技能考核 → 教学资源库。

厂商公开的 AI 能力包括识别：

操作步骤、流程顺序、器械使用、操作错误、步骤遗漏，以及护理领域的无菌规范等，并进行实时预警和自动评分。

它还支持教师人工复核评分，而不是把 AI 评分当成最终不可修改的答案。

这个设计是对的。

因为学校真正使用时一定存在：

AI 判断
→ 老师复核
→ 修正结果
→ 最终成绩。

特别是考试场景，不能把模型置信度直接等于最终成绩。

宝华另一个值得学习的是多源视频

它不是只布置一台普通摄像头。

其系统支持：

全景 + 实训操作台特写 + PLC屏幕 + 数控设备画面 + 专业设备信号

一起采集。

精细操作还使用 4K 特写摄像机捕获电路焊接、精密装配等细节。

这个跟我们前面的设计有一个明显冲突：

我们最初比较倾向于：

一个无遮挡工位 + 一个固定摄像头。

现在来看，产品层不能这样限制。

正确做法应该是：

一个实训项目，可以配置多个“感知源”。

例如：

发动机拆装 SOP

摄像头A：人体和整体操作
摄像头B：工作台俯视
摄像头C：零件细节
设备接口：扭矩数据
ASR：学生口述

每个步骤自己决定使用哪些数据源。

五、成都泰盟：重点学习“从评分到能力画像”

2026 年齐齐哈尔医学院的实际教学活动里已经使用 AI 进行“氧气吸入”等技能实践。

学校公开材料描述，系统可以：

追踪操作轨迹 → 获取节点时长 → 判断步骤顺序 → 判断规范性 → AI评分 → 形成能力报告。

最终报告不仅是一个分数，而包括：

技术精度、思维逻辑、人文关怀等能力维度。

这里对你们有一个很重要的产品启发。

假设机械装配一共有 30 步。

学生最终：

84 分

其实教学价值很有限。

真正有用的是：

安全规范          92
工具使用          88
操作流程          76
装配准确性        91
操作熟练度        68
故障处理          72

然后进一步告诉老师：

全班 62% 的学生在“步骤 17：扭矩复检”发生错误。

这个数据才可以反过来指导教师改教学。

所以未来最好形成：

SOP节点 → 评分项 → 能力项

三层映射。

六、威成亚：不要只把它当中学产品

虽然威成亚主要做初中理化生实验考试，但它是一个非常值得研究的“AI实操考试系统”。

2024 年在长春吉大附中力旺实验学校，它实际覆盖了 1600 多名学生。

每名学生操作时采用：

正视 + 俯视 + 侧视三个摄像头。

同时采用：

AI评分 + 人工评分。

整个产品体系包括：

考试管理、实验监考、视频采集、AI分析、人工批阅、双评、在线巡考、申诉仲裁、统计分析。

这实际上已经不是一个 AI 模型，而是一整套：

可信 AI 考试体系。

这个特别值得我们后期参考。

因为一旦你们从“日常训练”进入：

技能等级考试 / 职业技能大赛 / 课程考试

就会出现一个问题：

学生说 AI 判错了怎么办？

系统必须能提供：

原始视频 → AI命中步骤 → 时间点 → 判定依据 → 老师复核 → 修正记录。

也就是完整的考评证据链。

七、真正应该重点研究的工业产品：合米 AI-SOP

如果暂时完全不考虑“学校”，只考虑 AI-SOP 产品本身，合米是目前这轮调查中比较典型的产品形态。

它的产品已经明确拆成：

SOP数字化建模 → 作业指导 → 行为合规校验 → 关键工序防错 → 工序监测 → 拍照留痕 → 证据链归档。

硬件也产品化了：

设备	公开配置
边缘计算盒	RK3588 + NPU
工业触控一体机	RK3588 + 15.6寸屏
AI训练主机	RTX 4060 Ti
工业相机	1080P、可变焦

它非常值得我们参考的一点是：

AI运行在工位边缘侧。

不是所有视频实时上传云端。

这对于学校同样有价值：

实训工位
   ↓
本地AI推理
   ↓
输出结构化事件
   ↓
学校服务器
   ↓
考评/教学/数据分析

这样既降低带宽，又有利于隐私和低延迟。

八、轻象科技：我认为它隐藏着一个很关键的产品思想

轻象的官网有一句很重要：

支持“动作序列的快速定义和检测”。

它的 ActionStudio 被定位为动作 AI 低代码开发平台，核心能力是“人体动作 AI 语义理解”，产品还包括 AI 动作相机。其过程防错系统可以识别每个操作步骤，并检测错装、漏装。

这个比“模型识别准确率多少”更值得我们关注。

因为决定你们未来商业化能力的并不是：

YOLO 能不能把扳手识别出来。

而是：

学校拿来一个新的实训项目，我们多久能配置上线？

假如每新增一个 SOP：

调研2周
→ 采集100小时视频
→ 标注
→ 模型训练
→ 写代码
→ 联调
→ 2个月后上线

这个产品很难规模化。

而理想状态应该越来越接近：

老师创建SOP
↓
上传标准视频
↓
切分步骤
↓
选择每一步需要识别的事件
↓
标记工具/区域/动作
↓
系统自动形成训练数据
↓
训练/微调
↓
验证
↓
上线

所以我现在认为：

“SOP建模工具”会是你们这个产品真正的核心模块之一。

之前我们的方案里，这一块的重要性还不够高。

九、OTEK：它给了我们一套很清晰的视觉技术参考架构

OTEK 的公开方案比较技术化。

其工位 SOP 系统明确采用：

工业相机 + 深度学习 + 目标识别 + 动作轨迹分析 + 质量检测。

并采用双相机：

广角相机负责整个工位；

微距相机负责螺丝、零件等细节。

算法检测对象也不是只有“人体动作”，而包括：

产品、工具、设备类别及状态 + 操作顺序 + 动作规范 + 装配完整性 + 位置。

例如：

第1步：拿取M5螺丝
第2步：放入A孔
第3步：拿电动螺丝刀
第4步：锁紧A孔
第5步：拿第二颗螺丝
……

系统要识别的其实是：

人
+
物
+
人与物的关系
+
时间
+
顺序
+
结果状态

所以我现在不建议技术团队把核心路线简单描述为：

YOLO动作识别。

YOLO更适合作为其中一个目标检测能力。

整个视觉引擎应该至少包含：

目标检测
+
姿态/关键点
+
目标跟踪
+
动作/行为识别
+
区域关系检测
+
状态识别
+
时序分析

复杂工位再结合深度相机、设备数据或传感器。

AI 实训智能指导与考评平台

AI-SOP 引擎

十三、SOP本身应该怎么建模

我认为以后每个 SOP 步骤至少要有这种结构：

{
  "stepId": "S07",
  "name": "使用扭矩扳手紧固螺栓",
  "order": 7,
  "required": true,

  "recognition": {
    "personAction": "tighten",
    "tool": "torque_wrench",
    "target": "bolt_A",
    "region": "assembly_area_A",
    "equipmentSignal": null,
    "speech": null
  },

  "rule": {
    "previousStep": "S06",
    "allowSkip": false,
    "durationMin": 2,
    "durationMax": 10
  },

  "score": {
    "score": 5,
    "wrongTool": -3,
    "wrongOrder": -2,
    "missing": -5
  }
}

这样 AI 识别层负责告诉系统：

“学生拿着扭矩扳手，在 A 区域进行了紧固动作。”

SOP 引擎再判断：

“这是不是现在应该执行的步骤？”

这个解耦非常重要。

十四、产品端我建议最终形成四个工作台

学生端不应该只展示分数，而应该有标准 SOP 指导、当前步骤、实时提示、异常提示、训练结果、错误片段、标准动作对比和个人能力画像。

教师端应该负责班级、学生、课程、实训项目、训练任务、成绩、错误统计、视频复核和人工修正。

SOP编辑端应该成为核心，支持 SOP 树、步骤配置、工具配置、识别区域、动作事件、步骤关系、计时规则、扣分规则、标准视频和版本管理。

AI管理端则负责数据集、视频采集、标注、训练任务、模型版本、测试集、识别指标、部署、边缘设备和模型回滚。

这里面真正形成技术壁垒的，我认为不是学生页面，而是：

SOP Editor + AI Event Engine。

十五、还有一个关键问题：别试图让 AI 识别所有动作

竞品看下来，这一点也越来越清楚。

例如学生使用扭矩扳手：

摄像头可以判断：

拿了扭矩扳手。

但是到底有没有达到 35 N·m？

靠视频判断就非常不合理。

正确做法应该是：

AI视觉
判断：
拿了哪个工具
在哪操作
什么时候操作
顺序对不对

智能扭矩扳手
判断：
最终扭矩 = 34.8 Nm

再比如 PLC：

AI视觉判断：

学生是否进行了接线。

PLC/仪表数据判断：

接线结果和程序运行结果是否正确。

所以未来的 AI-SOP 引擎最好原生支持：

视觉事件 + IoT事件 + 设备事件 + 语音事件

统一进入 SOP 状态机。

这是捷安“视觉识别 + 传感器融合”已经在走的方向。

十六、我认为现在最值得做的 MVP

如果现在就开始做产品，我反而不建议一上来做：

“机械专业所有 SOP”。

应该挑一个：

10～20 个步骤、桌面固定工位、工具数量有限、遮挡较少、操作顺序明确、结果可观察

的实训项目。

例如：

零部件拆装
电气接线
螺栓装配
工具规范使用
机械部件检查

先跑通：

创建SOP → 录标准视频 → 采集训练数据 → AI学习 → 学生练习 → 实时识别 → 错误判断 → 自动评分 → 视频复盘 → 学情报告

完整闭环。

一旦这条链跑通，再换第二个完全不同的 SOP。

真正需要验证的核心 KPI 不是：

第一个 SOP 识别率做到 99%。

而是：

第二个、第三个 SOP 的上线成本能不能快速下降。

这决定你们做的是：

项目制解决方案

还是：

平台型产品。

十七、现在我会重点盯住的竞争空位

目前公开资料中，我暂时没有找到一个成熟产品同时把下面五件事做到位：

学校教师能够自己配置 SOP；通用动作/工具能力可以跨专业复用；新动作可以通过少量数据快速训练；视觉、语音、PLC、IoT 可以组成同一个步骤；训练、考试、复核、学情形成完整教学闭环。

捷安已经很接近，但强项仍然明显集中于轨道交通和特种作业。

友道也是行业型产品。

宝华的教学平台较完整，但公开资料里还看不到非常成熟的通用 SOP 建模工具。

合米、轻象、OTEK 的 AI-SOP 能力更接近工业现场，但教育教学产品能力明显不是其公开产品重点。

所以我认为真正值得你们占的位置不是：

“我们也有一个摄像头识别动作。”

而应该是：

一套面向职业教育的通用 AI-SOP 教、学、练、考、评平台。

底层做成可配置、可扩展的 SOP智能引擎，上层才针对机械、机电、汽修、轨交、电工、焊接等专业快速复制。
